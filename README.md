# Kurdish English Learning Platform (فێربوونا زمانێ ئینگلیزی)

پلاتفۆرمەکا پێشکەفتی بۆ فێربوونا زمانێ ئینگلیزی ب شێوەزارێ شیرینێ کوردی (بادینی / سۆرانی) دگەل زیرەکییا دەستکرد (AI).

---

## 🚀 شێوازێ نەقلکرن / بڵاڤکرن ل سەر GitHub (How to push to GitHub)

ژبەرکو فایلێن پرۆژەی هاتنە کورتکرن و رێکخستن ژ 500+ فایلان بۆ کێمتر ژ 40 فایلێن سەرەکی، نوکە گەلەک ب ساناهی دشێی پرۆژەی نەقل بکەیە سەر GitHub ب دوو رێکێن سادە:

### رێکا ١: ب ڕێکا تێرمیناڵێ (Git CLI) - پێشنیارکری
د ناڤ تێرمیناڵا پرۆژەی دا ڤان فرمانان بنڤیسە:

```bash
git init
git add .
git commit -m "Initial commit - clean structure"
git branch -M main
git remote add origin https://github.com/USERNAME/REPOSITORY_NAME.git
git push -u origin main
```
*(ناڤێ USERNAME و REPOSITORY_NAME ب ناڤێ هەژمار و ڕیپۆیا خۆ ل گیت هاب بگوھۆڕە)*

### رێکا ٢: ب ڕێکا بارکردنا ڕاستەوخۆ (Upload on GitHub Web)
ژبەرکو نوکە ژمارا فایلان کێمە، دشێی هەمی فایلێن پرۆژەی ڕاستەوخۆ (Drag & Drop) بکەیە سەر ماڵپەرا گیت هاب بێی هیچ کێشەیەک یان سنووردارکردنێ.

---

## 🛠️ دامەزراندن و کارپێکرن ل سەر ئامێرێ تە (Local Setup)

```bash
# دامەزراندنا پاکێجان
npm install

# کارپێکرنا سێرڤەری گەشەپێدانێ
npm run dev

# بنیاتنان (Build)
npm run build
```
